# Renhao Li

A minimal academic-style personal homepage.

- Live site: https://stdlibstring.github.io/
- `index.html`: page content
- `style.css`: layout and light/dark theme styles
- `theme.js`: theme toggle

The site is plain HTML, CSS, and JavaScript. GitHub Actions deploys these three files to GitHub Pages whenever changes are pushed to `main`.

To update the site, edit the files above and commit the changes. No build tool or package installation is required.
